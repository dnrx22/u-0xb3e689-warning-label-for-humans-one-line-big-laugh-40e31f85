This program writes a single line of comedy: the safety warning label that should come printed on every human being. It is funny first and plausible second — a coffee-powered, low-battery human that must not be shaken, must not be asked about work, and may only be handled with snacks — and it fits inside the 160-character limit.

## Run it

```sh
python3 main.py
```

The program writes the warning label to `entry.txt` inside the directory given by the `MAKEFUN_OUTPUT_DIR` environment variable (default `/output`), validates that it is exactly one line of 1–160 characters with no leading or trailing whitespace, and prints the sha256 of the written file. After writing, it reads the file back and checks it matches the label exactly, so a truncated or altered write can never pass silently. Running it twice produces byte-identical output.
